- Projeto pessoal, só o Jota trabalha nele. **Aqui vale commit e push direto na `main`**, sem PR. Isso substitui a regra global de PR (que vale só para projetos da Soluções) e as regras de fluxo git do plano (`docs/superpowers/plans/2026-10-04-claude-nextjs.md`).
- Siga o plano tarefa a tarefa, sem esperar merge entre tarefas. Commit e push a cada passo concluído.
- Ações manuais do Jota (Vercel, token TMDB, projeto Supabase na nuvem) ficam pendentes e são listadas ao final; não bloqueiam o resto.
